# Trò chơi tỉ lệ

Đẩy thiết kế tới cực trị để xem cái gì gãy. Cực trị không nói dối.

- 1 tài khoản so với 10.000 tài khoản: sổ tài khoản còn đọc nổi không?
- 1 luồng so với 1.000 luồng đồng thời: khoá nào tranh nhau? timeout nào nổ trước?
- Dữ liệu 1KB so với 1GB: còn giữ hết trong RAM không?
- 1 module so với 50 module: thời gian khởi động tăng tuyến tính hay bùng nổ?

Cái gãy ở cực trị là sai về mặt cấu trúc — sửa cấu trúc, đừng vá con số.
Cái chỉ chậm ở cực trị thì đo bằng số liệu thật rồi mới quyết có đáng sửa không.
